Link-bot

Link-bot is a personal Google Workspace integration operated by Jincheng Gao for the account owner’s own use. It connects a privately operated OpenClaw assistant to Google APIs using gogcli.

What it does

With the owner’s explicit Google OAuth consent, Link-bot can search and summarize Gmail, review calendar events, and work with authorized Drive files, documents, spreadsheets, contacts and tasks. The owner controls which services are authorized. Actions that send messages or change Google data require the owner’s instructions.

This public site provides documentation only. It offers no public account signup and does not display or store mailbox contents, Google files, or OAuth credentials.

Read the privacy policy for how authorized data is processed and how to revoke access.
